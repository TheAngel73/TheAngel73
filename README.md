## 📷 Provinia

Catalogo foto per Mac, nato per sostituire la Libreria di Lightroom quando le foto si modificano in Photoshop.
Pensato per grandi archivi su NAS (oltre 170 000 foto), funziona tutto in locale, senza cloud e senza abbonamenti.

- Cartelle, raccolte e set, parole chiave, stelle, etichette colore e bandierine, con importazione dal catalogo di Lightroom
- Griglia veloce, vista ingrandita con zoom e cursore dell'esposizione, dati di scatto e nome del luogo dalle coordinate GPS
- Mappa dei luoghi, ricerca duplicati, rinomina e spostamento dei file, conversione RAW → DNG, esportazione in JPEG
- App nativa per macOS: apri in Photoshop, trascina nel Finder, più cataloghi con password

Scritta in Python e JavaScript, con l'app per Mac in Swift. Sviluppata insieme a Claude Code.

## 📷 Provinia

A photo catalog for the Mac, built to replace Lightroom's Library for photographers who edit in Photoshop.
Designed for large NAS archives (170,000+ photos), it runs entirely on your Mac: no cloud, no subscription.

- Folders, collections and collection sets, keywords, star ratings, color labels and flags, with Lightroom catalog import
- Fast grid, loupe view with zoom and an exposure slider, shooting data and place names from GPS coordinates
- Places map, duplicate finder, file renaming and moving, RAW → DNG conversion, JPEG export
- Native macOS app: open in Photoshop, drag to the Finder, multiple password-protected catalogs

Written in Python and JavaScript, with a Swift Mac app. Built together with Claude Code.
